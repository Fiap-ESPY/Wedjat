# Issue tracker: TODO.md

O backlog, o andamento e a conclusão das features são registrados exclusivamente no `TODO.md` da raiz.

## Convenções

- Não criar GitHub Issues nem arquivos de tickets separados.
- Usar `[ ]`, `[~]`, `[x]` e `[!]` conforme a legenda existente.
- Adicionar requisitos e critérios verificáveis na seção da Sprint correspondente.
- Registrar dependências ou bloqueios diretamente no item.
- Quando um skill solicitar publicação ou leitura de ticket, atualizar ou consultar o `TODO.md`.
