# Triage labels

Os skills usam cinco papéis canônicos de triagem. Esta tabela registra os nomes adotados neste repositório.

| Papel do skill | Convenção do projeto | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Precisa de avaliação inicial. |
| `needs-info` | `needs-info` | Aguarda mais informações. |
| `ready-for-agent` | `ready-for-agent` | Está especificado e pronto para implementação. |
| `ready-for-human` | `ready-for-human` | Exige uma ação humana. |
| `wontfix` | `wontfix` | Não será implementado. |

Quando necessário, registrar o papel ao lado do item correspondente no `TODO.md`.
