# Domain docs

Este é um repositório de contexto único. Os skills de engenharia devem consultar a documentação de domínio antes de explorar ou modificar o projeto.

## Fontes

- `CONTEXT.md`, quando existir, define o vocabulário compartilhado do domínio.
- `docs/adr/`, quando existir, contém decisões arquiteturais duráveis.

Se esses caminhos ainda não existirem, prossiga silenciosamente. Eles são criados apenas quando o trabalho de modelagem de domínio identificar uma necessidade real.

## Regras de consumo

- Usar nos artefatos e no código os termos definidos em `CONTEXT.md`.
- Evitar sinônimos que o glossário rejeite explicitamente.
- Sinalizar qualquer proposta que contradiga uma ADR existente, em vez de sobrescrever a decisão silenciosamente.
